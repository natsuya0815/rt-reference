# RT Reference β v0.3.0 — 詳しい診療解説対応

2026年11月12日 更新。iPhone/PC対応の放射線治療リファレンス（静的PWA）。

## v0.3での変更

- **解説ページ方式**：項目をタップすると別画面で章立ての詳しい解説と原典リンクを表示。検索結果からも直接開けます。
- 乳癌 → 有害事象 → **「乳房再建のリスクについて」**を詳細記事に変更。インプラント/自家組織の合併症、時期、MROCとRT CHARMの数字の違い、PMRT/RNIと説明方法を収録。
- 「原発性脳腫瘍」を削除して**「膠芽腫（高悪性度神経膠腫）」と「髄膜腫」**に分割。
- 膠芽腫：60Gy/30fr、70歳以上の40.05Gy/15fr、TMZ同時/維持療法、ESTRO–EANOによるCTV、Radixact SIB＋FLAIRの検討、疑似増悪など。
- 髄膜腫：Grade別の適応とフォロー、RTOG 0539の54Gy/30fr、60/54Gy SIB/30fr、神経系晩期有害事象。
- 他癌種：前立腺20回・骨盤SIB、IPF合併肺癌、HCC 15分割・単回緩和、乳癌RNI/断端陽性、膵・直腸CRT、脳転移、SCLC、骨転移、DLBCL、ICI皮疹、HBO等を独立記事にして詳細化。
- **16癌種、50診療解説、48参考文献・資料**。既存のメモ・お気に入り・検索・癌種追加は維持。

## インストール・更新（GitHub Pages）

1. アプリの「癌種・情報源一覧」→ **JSONバックアップ** を先に取得してください（端末ローカル保存メモがある場合）。
2. このZIPを**展開**し、`rt-reference` リポジトリ直下へ**中身をすべて**アップロードしてください。ZIPファイル自体ではありません。
3. GitHubの同名ファイルを更新（置き換え）し、コミットしてください。**リポジトリ名・公開URLは変わりません**。
4. iPhoneのSafariで再読み込みしてください。PWAキャッシュにより旧版表示のことがあります。Version 0.3.0と表示されるか確認してください。
5. 新しい乳房再建記事は「乳癌 → 有害事象」、膠芽腫は「膠芽腫（高悪性度神経膠腫） → 処方線量 / 併用療法」から開けます。

## 各ファイル

- `index.html` UIとナビゲーション。`data.js` に依存します。
- `data.js` 医学データの実行用スナップショット。
- `data.json` 編集・監査用の同一医学データ。
- `clinical_notes.json` 収録解説の副本。
- `REVIEW_NOTES.md` ノートの一覧と公開前監査用。
- `manifest.webmanifest`, `sw.js`, アイコン画像：iPhone/PWAの設定とキャッシュ。

この版でも自動文献更新や外部AI生成は未実装です。追加したノートの全文はモデルに参照可能だった会話・要約に基づくため、**全過去チャットの網羅を保証しません**。

**公開の注意**：GitHub Pagesは公開サイトです。患者情報・診療記録・病院の機密は公開しないでください。ノートは匿名化・一般化していますが、間接的な識別のリスクも含めて `data.json` をレビューしてください。

線量制約は、分割回数・DVH指標・輪郭定義・線量計算法・既照射歴等で適用が変わります。引用を含む資料やRTOG試験の処方は、各対象集団での試験条件を照合してください。最終的な診療判断は担当医の責任で行ってください。
