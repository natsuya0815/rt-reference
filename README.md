# RT Reference β v0.5.3 — 放射線治療 臨床リファレンス

2026年11月18日更新版。既存の乳癌プランナー・直腸癌術前CRT・計算ツールを維持し、乳房・胸壁照射の放射線皮膚炎管理記事を追加。

## 乳房・胸壁照射の放射線皮膚炎管理（v0.5.3）

「**詳しい臨床解説**」→ 癌種「**乳癌**」→「**有害事象**」に新規記事 **n054** を追加。アプリ内検索（「皮膚炎」「リンデロンV」「bolus」）からも参照できます。

- 通常の温存乳房照射 42.56 Gy/16回：照射開始時に市販の低刺激性保湿剤を案内し、紅斑・掻痒出現時にリンデロンVクリーム0.12%などを検討。
- 胸壁照射 50.4 Gy/28回：bolusなしなら中リスクを基本とし、bolusや高皮膚線量、強い皮膚皺襞などがあれば初日からの予防的ステロイドを個別検討。
- 低・中・高リスクの3段階分類、Grade 1〜3の対応、湿性落屑の創傷管理、シリコーンフィルム、ヒルドイドとリンデロンVの国内添付文書上の適応・保険上の注意を収録。
- **リスク3段階は院内検討の暫定案で、検証済みスコアではありません。** 症状のない皮膚への予防的ヒルドイド／リンデロンV処方を、国内承認適応があるかのように扱わないでください。
- 出典：MASCC 2026、ドイツS3 2026、eviQ、2021年リスク因子メタ解析、国内電子添文、Mepitel Film第III相試験。

既存の匿名メモ・localStorage保存キー・乳癌照射範囲プランナー・線量計算ツールの実装は変更していません。

## 線量・BED・EQD2計算（独立ツール）

サイドバー **「◉ 線量・BED・EQD2計算」** から `dose-calculator.html` を開きます（iPhone、PC、PWAのオフライン利用に対応）。

- α/β値は**遅発性と急性の2つ**を設定。初期値3 Gy / 10 Gy。いずれも任意の正の値に変更でき、A/B両方に共通適用します。
- 画面内に**同じ計算表をA/Bの2つ**表示。各々「1回線量・分割回数・総線量・BED（遅発性/急性）・EQD2（遅発性/急性）」から任意の2項目を入力し、他の値をLQモデルで計算します。
- 計算済み欄を書き換えると、新たな入力条件として逆算（例：BEDと3回、またはBEDと1回線量）。
- A/Bの7項目と差分（B−A）を比較表示。「AをBへコピー」「4 Gy×5回の例」「クリア」を用意。
- BEDとEQD2が**同じα/β値に基づく場合**は2条件として独立せず、解が決まりません。α/β値が等しい場合も、異なるBED2つによる逆算はできません。
- 逆算した回数が非整数なら自動丸めをせず注意を表示。正の実数での数学的解を示すのみで、処方としての妥当性は保証しません。
- 基本式：`BED = nd(1+d/(α/β))`、`EQD2 = BED/(1+2/(α/β))`。等線量分割と基本LQモデルを仮定し、再増殖・修復・総治療期間・線量率・体積効果などの補正はしません。

入力値と結果は保存・送信しません。計算値の医療上の解釈、特に大線量分割と再照射では慎重な確認が必要です。

計算テスト：`node tests/dose-calculator.test.js`（21種の2項目ペアと逆算検証）。

## 臨床計算ツール（追加機能）

サイドバーの **「∑ 臨床計算ツール」** または `clinical-calculators.html` から起動します。iPhone/デスクトップ対応で、PWA利用時はオフラインでも使用できます。

- **推定CCr**：Cockcroft–Gault式（成人対象）。年齢・性別・体重・ScrからmL/minで表示。体重は入力値をそのまま使用し、低Scrの一律補正は実施しません。eGFRとは異なり、腎機能変動・低筋肉量・体格による精度制約に注意。
- **BSA**：藤本式（0.008883 × 身長[cm]^0.663 × 体重[kg]^0.444）。身長（cm）・体重（kg）からm²を小数第2位まで表示。JCOG掲載の藤本式を使用。
- **Child–Pugh**：Alb、T-Bil、PT活性%（PT-INRへの切替可）、腹水、肝性脳症の5項目で5〜15点とClass A/B/Cを表示。PT% >70/40〜70/<40、Alb >3.5/2.8〜3.5/<2.8、Bil <2/2〜3/>3 を採用。入力不足では結果を表示しません。

臨床計算値の入力・結果は保存・送信しません。計算結果を患者の投与量や放射線治療適応に自動適用しないでください。出典リンクと注意点は計算ページ内に記載。

ロジックの確認: `node tests/clinical-calculators.test.js`（標準Node.jsのみ、追加パッケージ不要）。

## 起動方法

### GitHub Pages
1. このZIPを展開し、ZIP直下にある**ファイルをまとめて**既存の `rt-reference` リポジトリ直下にアップロードしてください。
2. **`index.html` と `data.js` と `evidence.js` はセットで必須**です。`sw.js` などその他のファイルはPWAや確認用です。
3. GitHub Pages の URL は `https://<ユーザー名>.github.io/rt-reference/` のままで変わりません。
4. アップロード後に `RT Reference β v0.5.3` と表示されるか確認してください。旧版が残る場合はブラウザを再読み込みし、必要に応じてサイトデータのキャッシュを確認してください（**保存済みメモを消さないように注意**）。

### 旧版の単体HTML
リポジトリ内のv0.2単体HTML・ZIPは旧版の資料です。今回のプランナーは含みません。現行版は `index.html` から起動してください。

## データ管理

- `data.json` / `data.js`: 癌種・過去の詳細解説・出典一覧。
- `evidence.json` / `evidence.js`: 新しい病期別処方・比較・OAR制約。
- `clinical_notes.json`: 以前の臨床相談を整理した確認用データ。画面表示には `data.js` を使用。
- `REVIEW_NOTES.md`: 既存解説と今回の変更点を一覧。
- `sw.js`: オフライン/PWAキャッシュ。新規ファイル `evidence.js` もキャッシュ対象に追加。

`data.js` または `evidence.js` だけを更新すると、それぞれ対応するJSONと内容が食い違う可能性があります。JSONを編集したらJavaScriptの対応版も再生成してください。診療用データはGitの履歴で変更理由を管理してください。

## 安全上の注意

**このベータ版は診療判断の自動化・処方推奨システムではありません。** 病期分類、患者背景、組織型・分子分類、施設QA、化学療法適応、CT/MRI画像、DVH輪郭定義、再照射歴などは医師が判断します。

- 出典が見つからない、数値を原文で検証できない制約は意図的に未収載です。**「数値未収載（要照合）」は制約値ではありません。**
- 同一分割数でも照射部位・輪郭・臓器体積が違えば制約値を流用できません。異なる分割間の換算・補間は行いません。
- エビデンスの確実性「高・中・低・未確認」は暫定的な社内/個人用の整理であり、正式なGRADE審査の代替ではありません。
- ガイドライン閲覧ページの更新日と、そのガイドラインの正式発行年は異なる場合があります。発行年を併記しています。
- GitHub Pagesは公開URLです。医療機関の情報セキュリティ方針を確認してください。患者氏名・患者ID・生年月日・一意な症例背景、画像、診療録は**入力しない**でください。
- 症例メモ・独自知見・確認記録は `localStorage` に保存されます。暗号化された医療データベースではなく、端末間自動同期はありません。ブラウザデータ削除で失われるため、必要に応じてJSONバックアップを厳重に保管してください。
- アプリ更新は自動で医学情報を照合しません。出典の確認日・次回見直し日は医師によるチェックを記録するための機能です。

入力・結果は保存・送信しません。既存医学データ・検索・端末内メモ保存方式は維持しています。患者識別情報は入力しないでください。
