# RT Reference β v0.1.0

放射線治療専門医向けの **個人用・静的PWA（Webアプリ）** のベータ版です。

## 収録
- **15癌種**：非小細胞肺癌、小細胞肺癌、前立腺癌、膀胱癌、乳癌、脳転移、原発性脳腫瘍、肝細胞癌、膵癌、食道癌、直腸癌、頭頸部癌、子宮頸癌、悪性リンパ腫、骨転移・緩和照射。
- 重点：前立腺癌60 Gy/20 fr・CHHiPプロトコール直腸/膀胱制約、非小細胞肺癌CRT・QUANTEC、限局型小細胞肺癌BID、骨転移緩和照射など。
- 出典は日本・欧州・米国の学会ガイドラインと査読付き学術論文。**線量制約には必ず「条件・由来・原典」**を併記。
- 検索、癌種追加、お気に入り、独自メモ、JSON形式のバックアップ/復元、ダークモード、オフライン閲覧（公開後）。

## 最初に試す
1. ZIPを展開してください。
2. PCでは `index.html` を開くとほとんどの機能を試せます（`data.js` を同じフォルダに置く）。
3. iPhoneで使う場合は、以下のGitHub Pagesへの配置を推奨します。iOSの「ファイル」アプリからのローカル閲覧では、一部のWebアプリ機能が制限されることがあります。

## GitHub Pagesに配置する
1. GitHubで新しいリポジトリを作成します（公開する内容を確認）。
2. ZIPを解凍し、`index.html`、`data.js`、`sw.js`、`manifest.webmanifest`、アイコンなど**ZIP内のファイルをすべてリポジトリの直下**にアップロードします。ZIPそのもののアップロードでは動きません。
3. リポジトリの `Settings` → `Pages` で `Deploy from a branch`、ブランチ `main`、フォルダ `/ (root)` を選び保存します。
4. 数分後、GitHub PagesのURL（例：`https://ユーザー名.github.io/リポジトリ名/`）を開きます。URLはGitHubの`Settings` → `Pages` でも確認できます。
5. iPhoneでSafariから開き、共有メニューの「ホーム画面に追加」でアプリのように使えます。

⚠️ GitHub Pagesに公開した**アプリ本体と静的データは一般公開される前提**で扱ってください。患者情報、秘密情報、施設内部文書はリポジトリに入れないでください。

## データとバックアップ
- `data.js` は**初期医学情報**です。元データとして `data.json` も同梱しています。初期医学情報を変更した場合は、両者を同期してください。
- **癌種追加・個人メモは、端末ブラウザの `localStorage` に保存**されます。GitHubには自動反映されず、異なる端末間でも自動同期されません。
- 「癌種・情報源一覧」→「JSONバックアップ」で追加データを保存できます。復元すると既存の端末データを置き換えます。
- ブラウザデータを削除するとメモが消える場合があるため、定期的なJSONバックアップを推奨します。
- 検討メモは正式な診療プロトコールではなく**未検証**として扱い、承認フローは未実装です。

## このベータ版で未実装のもの
- 新規ガイドラインや論文の**自動巡回・内容反映**（次フェーズで検討）
- 医学文献の全文解析、患者個別リスク判定、レジメンの完全な処方詳細
- 端末間の同期、アカウント認証、医療機関システム連携
- 編集履歴に基づく医師承認ワークフロー
- その他多数の癌種における詳細OAR制約・予後データ（順次充実させるため枠のみ準備）

## 医療安全上の注意
本アプリは診療の最終判断を行うものではありません。線量制約は分割回数、輪郭定義、照射目的、既照射歴、併用療法、患者背景等に依存します。必ず原典と施設の正式プロトコールを確認してください。特にILD/IPF合併患者などで通常のDVH条件から安全性を推定しないでください。
